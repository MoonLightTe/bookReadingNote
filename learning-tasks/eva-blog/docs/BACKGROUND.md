## 1. 项目是什么

一个 EVA（《新世纪福音战士》）主题的个人技术博客。第一版（V1）是纯静态站点：文章是仓库里的 Markdown 文件，推送到 `main` 分支后，由 GitHub Actions 构建并发布到 GitHub Pages。

## 2. 目标与边界

**V1 要做到**

- 页面：首页、文章页、标签页、关于页、404
- Markdown 的全部内容都能正确渲染并带有 EVA 风格，包括 LaTeX 公式、代码块、Mermaid 图表
- 站内搜索、评论、RSS、Sitemap、昼/夜主题切换

**V1 不做**：阅读量、登录、数据库、自建后端。

**V2 的方向**：接入独立自建后端。V1 不为它预建任何接口层，原因见第 5 节。

## 3. 怎么走到这一步的

以下都发生在 2026-11-25。

1. 调研了社区做博客的做法，归纳为四条路线：静态博客、静态加无头 CMS、自托管动态平台、托管平台。你选了第一条。
2. 比较了 Astro、Hugo、Hexo、VitePress，定了 Astro + Vue。
3. 你提出不用现成主题，主题色和元素全部取自 EVA，第一版由你自己实现，我负责设计。
4. 我出了视觉稿，你认可了风格。
5. 你追加要求：Markdown 的所有内容都要支持，并点名了 LaTeX、代码块和流程图。视觉稿因此增加了 Markdown 页签。

## 5. 分工与规则

**分工**：第一版的代码由你本人实现。我负责调研、视觉设计和架构文档。

**通用开发纪律**：以 devbase §1 为准，这里不重复。这个项目是 PC 桌面端 Web 项目，适用 web-pc 规范包。

**本项目特有的规则**

- 不为 V2 预建抽象层。V2 接后端时改三处：`Comments.astro`、各页面对 `getCollection('blog')` 的调用、新增一个阅读量组件。
- 深浅色分三套规则：站点跟随昼/夜；代码块和图表面板恒为深色。
- 主题标记是 `html[data-theme="day"]` 或 `"night"`，由 `<head>` 里的内联脚本在首次绘制前写入。
- 四种颜色各有唯一职责：紫用于链接和焦点，绿用于强调和状态，橙用于话数和标签，红只用于警示和话数编号。
- 标题字体用开源的思源宋体 Black（Noto Serif SC 900），不用商业字体 Matisse EB。
- EVA 是他人的作品。只用配色和警示条、HUD 括角这类通用母题；不用 NERV 标志、EVA 标题字标、角色图像和截图。
- 对比度要求：文字与背景不低于 4.5:1，图形不低于 3:1。红色编号要按标题卡的极性取色，白卡上用暗红 `#C81E0C`，黑卡上用亮红 `#FF4D42`。

## 7. 实现前必须知道的事实

- **Astro 7 换了默认的 Markdown 处理器。** 默认的 Sätteri 不能直接用 remark/rehype 插件，所以本项目改用 Unified。网上大部分公式教程用的是旧的配置项名，照抄会配错。
- **astro-mermaid 的 `autoTheme` 只能在 Mermaid 内置的两套主题间切换**，用不了自定义配色。这是图表面板定为恒深色的原因。
- **Pagefind 的中文分词只在 extended 构建里支持**，而 `npx pagefind` 默认装的就是它。页面必须带 `lang` 属性。
- **本机环境**：Node 24.22.1，满足 Astro 7.4.13 要求的 22.23.4 以上；pnpm 10.9.0。
