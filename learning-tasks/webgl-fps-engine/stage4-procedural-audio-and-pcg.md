# 阶段四实战任务：程序化音频与 Demoscene 建模 (第 17 - 20 周)

> **目标**：彻底丢弃几十兆的外部音频 MP3 和 3D 模型 `.gltf` 资源包，用算法与数学公式纯代码实时生成声音与世界。

---

## 📚 对应阅读章节与理论输入

1. **MDN Web Audio API 权威指南与声音物理学**
   * 音频上下文 `AudioContext`
   * 信号源：`OscillatorNode`（正弦波、方波、锯齿波、三角波）、AudioBuffer 白噪声
   * 音效处理链：`GainNode`（音量衰减包络）、`BiquadFilterNode`（高通/低通滤波器）、`StereoPannerNode`（空间立体声平移）
2. **Demoscene 极客建模技术 (Procedural Modeling)**
   * 用代码操作网格几何体：布尔运算（CSG）、参数化拉伸、挤出与细分。

## 🛠️ 动手实操任务清单

### 任务 4.1：使用 Web Audio API 纯代码实时合成完整游戏音效库
* **任务描述**：
  * **完全不加载任何 `.mp3`、`.wav` 或 `.ogg` 音频文件**。
  * **枪击开火声（Gunfire）**：
    * 第一层（冲击感 Transient）：短促（0.04 秒）的三角波向下快速滑音，模拟撞针与气爆。
    * 第二层（爆炸轰鸣 Boom）：生成 0.2 秒的白噪声缓冲区，接一个低通滤波器（Low-pass Filter）使频率在 0.15 秒内从 800Hz 快速衰减至 60Hz。
    * 第三层（回响 Decay）：增益指数衰减曲线模拟室外开阔码头的空气回声。
  * **弹壳落地与换弹脆响（Shell Drops & Reload）**：
    * 用高频方波脉冲叠加带通滤波器，模拟金属撞击地面的微小高音敲击。
  * **动态背景战术氛围（Procedural Tension & Radio）**：
    * 用双低频正弦波振荡器产生微妙的相位干涉，生成深沉有压迫感的环境低鸣（Drone）。
    * 暴露或战斗状态下，动态提升节拍频率；击杀敌人时发出高频短促电台确认蜂鸣（Radio Beep）。
* **验收标准**：
  * 在页面上按下鼠标左键，能听到层次丰富、震撼有冲击力的枪声与回音；被敌人追杀时背景音效自然升调变紧张，全套音效代码体积不超过 15KB。

### 任务 4.2：纯代码拼装几何武器与港区道具模型 (Procedural Assets)
* **任务描述**：
  * 不引入任何 Blender 导出的 `.fbx` 或 `.gltf` 文件。
  * **制式突击步枪模型**：
    * 枪身主体：长方体 `BoxGeometry` 经倒角拉伸。
    * 枪管与消焰器：细圆柱体 `CylinderGeometry`。
    * 战术导轨与弹匣：带有倾斜角的梯形几何体组合。
    * 瞄准镜与全息准心：中空圆环与发光片元材质。
  * **码头起重机与集装箱**：
    * 编写循环函数生成集装箱群，利用纯代码通过不同颜色与涂装标号材质批量摆放。
    * 用几何桁架管结构拼出几十米高的岸边巨型集装箱门式起重机。
* **验收标准**：
  * 纯依靠 JS 代码的几百行几何顶点组合，在场景中渲染出一套有工业机械科幻质感的突击步枪与港区码头。

### 任务 4.3：3D 世界空间到 2D 屏幕投影的战术 HUD 界面
* **任务描述**：
  * 使用轻量级 HTML5 DOM + SVG 打造现代战术风格 UI：
  * **指南针罗盘磁带（Compass Tape）**：
    * 屏幕正上方放置水平滚动的刻度盘，随玩家当前视线偏航角（Yaw）实时无限循环水平平移（显示 N、NE、E、SE、S、SW、W、NW 与精确度数）。
  * **3D 世界目标点投影（World Space Markers）**：
    * 将 3 个中继器和撤离点的世界三维坐标 $(x, y, z)$，通过相机的 `project(camera)` 方法转换为屏幕归一化坐标（NDC），映射至屏幕像素。
    * 目标在玩家正前方时，在目标头顶悬浮菱形框与距离读数（例如 `中继 A · 42m`）；若目标在视野外，将标记贴合停留在屏幕边缘并指示方向。
  * **受击方向动态红弧（Damage Direction Indicator）**：
    * 受击瞬间，计算攻击者方位角相对于玩家朝向的相对角度，在屏幕中央弹出带有弧度的 SVG 红色警告弧，并随时间平滑淡出。
* **验收标准**：
  * HUD 界面极富现代军事与科幻战术感，目标标记精准锁定在远处的 3D 物体上方，转动视角时罗盘与标记平滑跟随。
