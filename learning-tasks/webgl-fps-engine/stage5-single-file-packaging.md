## 🛠️ 动手实操任务清单

### 任务 5.1：跨端输入控制系统（手柄 + 移动端虚拟双摇杆）
* **任务描述**：
  * **手柄支持（Gamepad API）**：
    * 监听 `window.addEventListener("gamepadconnected")`。
    * 左摇杆控制角色平移，右摇杆控制视角环视（加入 0.15 摇杆死区避免漂移）。
    * RT 键开火、LT 键瞄准、A 键跳跃、B 键下蹲、X 键换弹、Start 键暂停。
  * **移动端触屏自适应（Touch Controls）**：
    * 左半屏：动态虚拟触摸摇杆（手指按下位置即为摇杆圆心，滑动计算移动方向）。
    * 右半屏：滑屏转向视口 + 环形布局的透明开火、跳跃、开镜按钮。
    * 适配全面屏与刘海屏安全边距（`env(safe-area-inset-top/bottom/left/right)`）。
* **验收标准**：
  * 在 PC 电脑上插上手柄即刻顺畅操控；在手机浏览器上打开自动切出虚拟双摇杆并适配全屏。

---

### 任务 5.2：性能基准测试模式 (Benchmark) 与自适应画质调节
* **任务描述**：
  * 支持 URL 查询参数触发测试（如 `?bench=1` 或 `?q=low`）。
  * **性能监控**：计算平均帧时间、中位数、P99 延迟（99% 帧的渲染耗时）与实时 FPS。
  * **画质分级管理（Low / Medium / High / Ultra）**：
    * `Low`：关闭软阴影、关闭反射倒影、降低分辨率缩放（DPR 0.75）。
    * `Ultra`：开启全分辨率 PCSS 软阴影、高采样率雨夜水坑倒影与全屏抗锯齿。
    * 自动档（Auto）：根据用户设备 GPU 信息自动匹配推荐档位。
* **验收标准**：
  * 游戏设置面板中可自由切换画质，低配置手机能流畅运行 60 帧，高性能 PC 呈现顶级画面。

### 任务 5.3：单文件极客封包工程流水线 (Single-File Inliner)
* **任务描述**：
  * 搭建一套自动化打包脚本（可基于 Vite 或 Rollup）：
  * **Three.js 定制 Tree-shaking**：
    * 只打包游戏中实际用到的核心模块（`WebGLRenderer`、`Mesh`、`ShaderMaterial`、数学库等），剔除所有没用到的 Loader、辅助对象与冗余材质。
  * **单文件内联（Single HTML Bundling）**：
    * 将所有 CSS 压缩并内联至 `<style>` 标签中。
    * 将所有 GLSL 着色器代码转为压缩字符串内联在 JS 中。
    * 将编译压缩（Terser/Uglify）后的整套逻辑 JS 直接内嵌在单一 `<script>` 标签内。
  * **体积审计**：
    * 最终生成的整个 HTML 文件大小控制在 **350KB ~ 500KB** 之间。
* **验收标准**：
  * 产出的单一 `.html` 文件，断网状态下在任意现代浏览器双击直接打开，即刻秒开进入 3D 港区世界并可流畅游玩全部关卡！
