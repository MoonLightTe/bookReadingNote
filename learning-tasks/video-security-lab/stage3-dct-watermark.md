# Stage 3: 频域 DCT 水印与 ORB+RANSAC 透视校正 (P1-L3)

- **所属路线**：Phase 1 · Level 3（事后盲溯源与抗屏摄攻击）
- **DAG 依赖**：前置为 `P1-L1`（HLS AES-128 基础）
- **预计耗时**：2 ~ 3 周
- **环境要求**：Python 3.10+, OpenCV (`opencv-python`), NumPy, Matplotlib。

---

## 核心任务与行动指令
1. **8×8 分块 DCT 嵌入与提取**：
   - YUV 色彩空间提取 Y 分量；
   - 调制中频系数对 $(4,3)$ 与 $(3,4)$ 的差值，嵌入二进制水印；
   - 验证无退化原图 BER 恒为 $0.00\%$（硬性止损条件）。
2. **退化集模拟与双路径对比**：
   - 模拟 $0^\circ \sim 40^\circ$ 透视畸变；
   - 路径 1：无同步直接提取；
   - 路径 2：ORB 特征匹配 + RANSAC 估计单应矩阵逆变换复原后再提取。
3. **输出论文级 BER 对比图表**。
