# Stage 5: Windows 内核只读枚举与回调完整性防御

- **所属路线**：路线 B · 模块 B2
- **预计耗时**：3 周
- **环境要求**：Windows 10 1703 虚拟机, 开启测试模式 (`bcdedit /set testsigning on`), 宿主机 VS2022+WDK, WinDbg 双机调试。

---

## 核心任务与行动指令
1. **规避 PPL 签名死胡同**：
   - 采用只读枚举 `CallbackList` 快照与范围校验方案，避免直接写入导致的蓝屏或签名拦截。
2. **合法范围校验**：
   - 遍历 `PsLoadedModuleList` 校验所有已注册回调指针是否落在合法驱动模块内存区间；
   - 发现脱离合法驱动的指针立刻输出安全告警。
