## 💡 如何开启跨书主题阅读？
当同一个领域积累了 2 本或以上的书籍时，对 Agent 发送：
> *"围绕 `#高可用` 展开主题阅读"* 或 *"对比《DDIA》和《SRE》在容错设计上的不同视角"*

Agent 将根据 [.templates/topic-synthesis-template.md](../.templates/topic-synthesis-template.md) 引导您建立跨书概念拉齐与批判性研讨卡片。
